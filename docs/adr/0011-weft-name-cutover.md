# Weft 名称的一次性切换

项目统一使用产品名 `Weft`、包名及路径标识 `weft`、环境变量前缀 `WEFT_`。本次重命名采用一次性切换，不增加旧名称别名、自动数据库迁移或浏览器凭据回退；用户已明确允许丢弃旧数据并重建数据库，以避免为单人本机项目维护迁移与兼容逻辑。本次实施按此决定完成切换。

默认数据库改为 `data/weft.sqlite`。实施时先正常停止本项目服务、等待数据库及命令清理，再删除本项目原默认库及其 SQLite 附属文件，以现有初始化逻辑创建新库；自定义 `--db` 文件保留。历史、Project、模型、API key、MCP 和偏好需重新配置，浏览器需重新打开新启动 URL。

管理凭据统一为 `WEFT_MANAGEMENT_TOKEN`、`x-weft-management-token` 和 sessionStorage 的 `weft-management-token`；继续保留 ADR 0004 的鉴权、启动时环境移除和命令环境凭据剔除规则。临时工作目录改用 `/tmp/weft/` 及 `/tmp/weft-executor-`，继续保留服务／Agent 隔离、路径验证和私有权限。用户级指令目录继续采用 ADR 0006 已规定的 `~/.weft/`。

切换覆盖当前源码、测试、脚本、文档链接和已确认归属本项目的本机启动路径。Git 历史、历史任务原文、第三方资源与共享 Skills 保留原貌；旧临时目录不作为新服务的输入，不进行全机通配删除。ADR 0004 中的旧 header 和 scratch 路径在实施时同步更新，其安全边界与执行语义保持不变。
